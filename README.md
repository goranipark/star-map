# 폴라리스의 별자리

초등학생이 북극성 주변의 별자리를 직접 이어 보고 신화 이야기를 읽는 React 기반 학습 게임입니다. 모든 진행 기록은 현재 브라우저의 `localStorage`에만 저장됩니다.

## 개발 명령

```sh
npm install
npm run dev
npm test
npm run check:art
npm run build
npm run test:browser
npm run preview
```

- `npm test`: 카메라, 진행 저장, 별자리 데이터, 좌표 투영, 배경 별밭, 카드 파일명을 네트워크 없이 검사합니다.
- `npm run check:art`: `src/data/constellations.json`에 정의된 29개 삽화와 `public/art`의 실제 파일을 대조합니다. 파일이 덜 만들어진 개발 단계에서는 누락 목록을 출력하고 실패 코드로 끝납니다.
- `npm run build`: `dist`에 정적 배포 파일을 만듭니다. Vite의 상대 `base`를 사용하므로 GitHub Pages의 하위 경로에서도 동작합니다.

## 삽화

### 작품 편집·저장 회귀 검증

`npm run test:browser`는 빌드된 `dist`를 전용 로컬 서버로 열고 시작 대화·모바일 넘침·입력·저장·초안·여러 탭·초기화 실패·오프라인 테스트를 차례로 실행한 뒤 서버를 종료합니다. Playwright는 개발 의존성으로 고정되어 있습니다. Linux CI는 `npx playwright install --with-deps chromium`으로 설치한 Chromium을 사용합니다. Windows는 기본 Edge를 사용하며 `BROWSER_CHANNEL=chromium`으로 Chromium을 선택할 수 있습니다.

초기화는 진행 기록과 모든 탭의 작성 중인 성좌 초안을 함께 지웁니다. 삭제 도중 실패하면 가능한 한 초기화 전 데이터를 복구하고 확인 화면을 유지한 채 오류를 알립니다. 사용자가 다시 시도해 실제 삭제에 성공한 뒤 화면도 초기화합니다.

작성 중인 성좌는 별도의 초안 저장소에 자동 저장됩니다. 도감 이동이나 새로고침 후 성좌 만들기를 다시 열면 선과 입력 내용이 복원됩니다. 다른 새 탭에서도 최근 초안을 이어 받을 수 있고 이후 편집은 탭별 저장 슬롯을 사용합니다. 작품 저장에 성공하면 해당 초안을 지웁니다. 저장공간 오류로 초안을 보관하지 못한 경우 화면에 실패를 알립니다.

퍼즐 완료 기록은 마지막 정답 연결 즉시 저장 요청하며 1.8초 연출은 이야기 화면 전환만 지연합니다. 편집·퍼즐 화면 또는 저장 중에는 업데이트 적용 안내를 보류하고, 다른 탭이 업데이트해도 현재 편집 화면을 자동 새로고침하지 않습니다. 편집 화면을 나간 뒤 업데이트를 적용할 수 있습니다.

진행 저장은 Web Locks로 탭 간 읽기·수정·쓰기를 직렬화하며, 최신 저장값에 해당 동작만 적용합니다. 다른 탭의 변경은 `storage` 이벤트로 화면에 반영합니다. 삭제·교체 대상이 바뀌었으면 중단하고 다시 선택하도록 안내합니다. 저장 실패 재시도도 오래된 전체 스냅샷 대신 작업을 최신 기록에 재적용합니다. Web Locks를 제공하지 않는 환경에서는 안전하지 않은 동시 쓰기 대신 저장 실패를 알립니다.

`node scripts/check-preservation.mjs`는 로컬 미리보기에서 완료 연출 중 이동, 실제 두 탭 동시 저장·동기화, 초안 복원과 탭 분리, 마지막 보관 칸에 대한 동시 저장 충돌을 검증합니다. `check-offline.mjs`에는 다른 탭 업데이트 중 편집 화면 유지 검증도 포함됩니다.

`node scripts/check-weaver.mjs`는 실행 중인 프로덕션 미리보기(`http://127.0.0.1:4173`)에서 별 잇기 단계 왕복, 기존 선 삭제·복원, 저장 실패 안내 및 재시도를 검증합니다. Playwright와 Microsoft Edge가 필요하며 `PLAYWRIGHT_MODULE`에 별도 설치의 `playwright/index.mjs` 경로를 지정할 수 있습니다. 다른 미리보기 주소는 `PREVIEW_URL`로 지정합니다. 테스트는 별도 브라우저 세션을 사용합니다.

멀티포인터, 포인터 취소·캡처 해제·화면 밖 종료도 검증합니다. `WEAVER_FULL=1`로 실행하면 12칸이 찬 상태에서 선택한 작품만 교체하고 저장 실패 시 기존 작품을 보존하는 흐름을 확인합니다. 합성 포인터 테스트이며 실제 휴대폰·태블릿 검증은 별도로 진행합니다.

저장 실패 시 기록은 현재 세션에 유지하고 재시도를 안내합니다. 성좌 완성 화면에서는 PNG 다운로드도 가능합니다. 저장된 작품은 좌표·텍스트·연결선 참조를 검사하고, 손상된 항목만 읽기 결과에서 제외합니다. 읽는 과정에서 저장 원본을 덮어쓰지 않습니다.

삽화 파일은 `public/art/<별자리id>-<컷번호>.png` 규칙으로 넣습니다. PNG, JPG, JPEG, WebP를 지원하며 1024×1024 정사각형을 권장합니다. 자세한 제작 및 마지막 별자리 오버레이 절차는 `public/art/README.md`와 `art-prompts.md`에 있습니다.

현재 저장소에는 다섯 별자리의 이야기 삽화 29컷과 시작 화면용 폴라리스 삽화 5종이 포함되어 있습니다. 이야기 삽화가 누락되면 앱은 별자리 도형으로 안전하게 대체합니다.

## 소리와 오프라인 사용

배경음과 퍼즐 효과음은 외부 음원 파일 대신 브라우저 Web Audio로 생성합니다. D 장조 오음음계의 드론과 느린 글라스 벨 멜로디가 이어지고, 별 연결음도 같은 악기와 잔향을 사용해 연결 진행률에 따라 상승합니다. 마지막 선의 높은 음은 완성 시 Dadd9 화음과 별가루 같은 스윕으로 자연스럽게 이어집니다. 첫 사용자 입력 뒤 시작하며 상단의 소리 버튼 상태가 진행 설정에 저장됩니다.

프로덕션 빌드는 `scripts/offline-plugin.js`가 HTML·JS·CSS·폰트·아이콘의 실제 빌드 목록과 내용 해시를 포함한 `dist/sw.js`를 생성합니다. 필수 파일 전체의 선캐시가 완료되면 오프라인 실행이 가능합니다. 일부 파일이 없거나 설치 중 연결이 끊기면 새 워커 설치를 취소하고 기존 버전을 유지합니다. 최초 접속 자체가 오프라인이면 설치할 수 없습니다.

HTML과 필수 자산은 해당 빌드 버전에 고정하며, 업데이트 안내에서 적용한 뒤 새 버전으로 전환합니다. 업데이트 직전 탭의 자산 요청을 위해 직전 셸 캐시 하나를 보존합니다. 캐시 이름은 배포 경로별로 분리합니다. 기존 저장 데이터의 키와 버전은 바꾸지 않습니다.

삽화는 워커가 제어하는 동안 요청에 성공한 파일만 최대 40개 보관하며 버전 전환 시 비웁니다. 미방문 이야기 삽화는 오프라인에서 별자리 도형으로 대체됩니다. 최초 로딩에서 워커 제어 전에 요청한 삽화는 아직 캐시되지 않을 수 있습니다.

삽화도 파일 내용과 경로를 버전 해시에 포함합니다. 따라서 같은 이름의 그림만 교체한 빌드도 새 워커가 만들어집니다. 삽화는 여전히 선캐시하지 않으며, 새 버전에서 처음 받을 때 HTTP 캐시도 갱신해 이전 그림이 남지 않도록 합니다.

빌드 후 `node scripts/check-offline.mjs`로 임시 서버의 하위 경로에서 첫 설치 후 오프라인 실행, 사용자 승인 업데이트, 필수 파일 누락 시 이전 버전 복구를 검증합니다. 위와 같은 Playwright/Edge 환경을 사용합니다.

## GitHub Pages 배포

`main` 푸시와 PR에서 `Regression tests`가 단위 테스트·빌드·Chromium 회귀 검증을 실행합니다. 저장소의 Actions 화면에서 `Deploy to GitHub Pages` 워크플로를 수동 실행하면 같은 검증을 모두 통과한 경우에만 `dist`를 업로드하고 배포합니다. 저장소 Settings → Pages의 Source는 GitHub Actions로 설정해야 합니다.
