# 시작 화면 버전

- **ver1**: 캐릭터 적용 전 북극성·회전 성도판 시작 화면. TitleScreenV1.jsx 및 TitleScreenV1.module.css에 보존.
- **ver2**: 캐릭터, 우주 배경, 대화와 선택 버튼을 포함한 현재 시작 화면. TitleScreenV2.jsx 및 TitleScreenV2.module.css에 보존.
- 기본 접속은 ver2. URL에 ?title=ver1 또는 ?title=ver2를 붙이면 해당 버전을 볼 수 있습니다.
- 두 버전은 같은 별자리 학습 화면과 진행 기록을 사용합니다. 버전 선택은 시작 화면에만 적용됩니다.
