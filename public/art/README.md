# 삽화 넣는 곳

이 폴더에 그림 파일을 넣으면 이야기 슬라이드에 자동으로 뜹니다.

## 파일 이름 규칙

```
<별자리id>-<컷번호>.png
```

| 별자리 | 신화 장면 | 별자리 컷(마지막) |
|---|---|---|
| 작은곰자리 | `ursa-minor-1` ~ `-5` | `ursa-minor-6` |
| 큰곰자리 | `ursa-major-1` ~ `-5` | `ursa-major-6` |
| 카시오페이아자리 | `cassiopeia-1` ~ `-5` | `cassiopeia-6` |
| 케페우스자리 | `cepheus-1` ~ `-4` | `cepheus-5` |
| 용자리 | `draco-1` ~ `-5` | `draco-6` |

- **정사각형**, 1024×1024 권장. 형식은 **PNG · JPG 아무거나** 됩니다 (`.png` `.jpg` `.jpeg` `.webp`)
- 이름을 정확히 맞춰야 합니다 (대소문자·하이픈 포함)
- 넣은 뒤 브라우저를 새로고침하면 바로 보입니다
- **파일이 없으면** 별자리 모양 그림이 자동으로 대신 나옵니다 — 그림이 없다고 화면이 깨지지 않습니다

## ⚠️ 그림에 별자리를 그려 넣지 마세요

이미지 생성기는 별을 정확한 위치에 찍지 못합니다. 개수가 늘거나 비율이 틀어진
별자리를 그려 버리는데, 아이들은 바로 앞 퍼즐에서 **실제 좌표로 찍은 정확한 별자리**를
이어 놓고 오기 때문에 그림에서 다른 모양을 보면 그대로 오개념이 됩니다.

배경에 흩뿌린 별가루는 괜찮지만, **선으로 이어진 별 무리는 안 됩니다.**
프롬프트에 이 지시가 이미 들어 있습니다.

## 마지막 컷 = 별자리 컷

각 이야기의 **맨 마지막 한 장**은 옛 성도에 실려 있던 그 그림입니다 —
**진짜 별 배치 위에 곰·왕비·용의 몸을 겹쳐 그린 것.**
이야기가 "오늘 밤 직접 찾아보자"로 마무리됩니다.

**AI는 몸의 윤곽선만 그리고, 별은 앱이 그 위에 정확하게 얹습니다.**

### 만드는 순서

1. 주소 끝에 `?tune=1` 을 붙여 엽니다 → `http://localhost:5173/?tune=1`
2. 그 별자리 이야기의 **마지막 컷**으로 넘깁니다
3. 오른쪽 판 맨 아래 **`○○자리 내려받기`** 를 눌러 **별자리 참고 그림**을 받습니다
4. 받은 `참고-○○자리.png` 를 AI 대화창에 **함께 올리고**, `art-prompts.md` 의
   **★ 별자리 컷** 프롬프트를 붙여넣습니다
5. 나온 그림을 이 폴더에 넣습니다

### 얹는 위치 맞추기

그림이 들어오면 별자리를 몸 위 정확한 자리로 옮겨야 합니다.

1. 같은 `?tune=1` 화면에서 **좌우 · 위아래 · 크기 · 회전** 막대를 움직입니다
2. **복사하기** 를 누릅니다
3. `src/data/constellations.json` 에서 그 컷의 `"overlay"` 값을 붙여넣은 값으로 바꿉니다

```json
"overlay": [
  { "id": "ursa-minor", "x": -4, "y": 2, "scale": 0.92, "rotate": 12 }
]
```

옮기고 · 키우고 · 돌리는 것은 **별자리 모양을 바꾸지 않습니다.** 별 사이의 비율이
그대로라 별자리는 계속 정확합니다. 회전은 오히려 자연스럽습니다 — 별자리는 실제로도
밤새 북극성을 중심으로 돕니다.

`?tune=1` 없이 열면 이 판은 나오지 않으므로, 학생들에게는 보이지 않습니다.
